## 设计要点

- **5 Tab 底部导航**：首页 / AI 问答 / 考试中心 / 排行榜 / 我的
- **AI 问答**：三大知识库（私域内容 / 产品话术 / HCP360）+ 行内溯源 chip + 半层抽屉
- **异议处理双层评分**：环节能力 70%（同理共情/深入探询/异议澄清/确认共识）+ 综合素养 30%（专业度/合规性/流畅度/共情力）
- **病例考核 5 维**：疾病知识 / 诊疗路径 / 药物特点 / 证据掌握 / 沟通合规
- **个人中心**：异议 4 维雷达图 + 病例 5 维雷达图，与团队均值实虚线对照

## 技术

- 静态 HTML + CSS + 内联 SVG sprite，无构建、无 JS 依赖
- 诺和诺德蓝调主色 + 三 3D 卡通医生头像（王伟 / 李雪 / 张强）
- 375px 移动基线，多屏并排展示
